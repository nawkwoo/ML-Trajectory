# 프로젝트 개요 (쉬운 버전)

## 우리가 풀 문제와 목표
- 문제: 로봇 팔 엔드이펙터 3D 궤적(텍스트 파일 7번째 컬럼 `x/y/z`)을 보고 동작 클래스(circle, diagonal_left/right, horizontal, vertical)를 맞추는 분류기.
- 목표: 데이터가 적고 노이즈가 있는 환경에서, **설명 가능하고 효율적인** 모델을 만들고 평가/시각화까지 제공.

## 데이터와 전처리 흐름 (기초 용어 포함)
- `(T,3)` 시계열: T는 시간 축 길이(스텝 수), 3은 x/y/z 좌표 축. 예) 길이 256이면 256개 시점의 (x,y,z) 점을 가진 배열.
- `std`(표준편차): 데이터가 평균에서 얼마나 퍼져 있는지. 정규화할 때 `(값-평균)/표준편차`로 스케일을 맞춰 축마다 분포를 비슷하게 만듦.
- 파이프라인:
  1) TXT 로드 → 콤마 분리 후 7번째 컬럼을 `x/y/z` float로 파싱 → 시계열 `(T,3)`.
  2) 길이 가변 → 선형보간으로 고정 길이(기본 256) 리샘플. (길이 차이를 제거, 모델 입력 고정)
  3) 정규화 → 시퀀스별 평균 0, 표준편차 1. (옵션) 전체 std 기반도 가능.
  4) 노이즈 프로파일 추정 → 오리지널 vs 노이즈 세트의 축별 표준편차 차이를 계산해 “노이즈 느낌”을 수치화.
  5) 증강
     - 오리지널만 적극 증강: 노이즈 프로파일 기반 가우시안 노이즈, 소각도 회전(±5~8°), 시간 스트레치(0.95~1.05), 짧은 구간 마스킹.
     - 노이즈 세트: 추가 노이즈 없이 전처리만(신호 희석 방지).
     - 합성 노이즈 샘플은 **학습에만** 사용, 평가에는 포함하지 않음.

## 데이터 분할 규칙
- 오리지널+실제 노이즈를 합쳐 stratified split (ML: train/test, DL: train/val). 합성 노이즈는 train에만 추가.
- 단일 split 편향을 줄이려면 k-fold 교차검증(추천 5-fold)으로 평균/분산 지표를 기록.
- 깨끗/노이즈를 따로 평가하는 옵션을 추가해 강건성 확인 예정.

## 사용 알고리즘과 선택 이유
- **SVM (RBF 커널)**: 적은 데이터에서 결정 경계를 잘 학습, 특징 기반이라 해석/중요도 분석 용이.
- **특징 세트**: 경로 길이, bounding box, 속도/가속도/저크 통계, 방향 변화량, 시간정규화 샘플 좌표 → 물리적 의미가 있어 설명 가능.
- **CNN+BiLSTM (소형)**: CNN으로 짧은 패턴, BiLSTM으로 전체 문맥을 읽어 시계열 구조를 직접 학습. 파라미터를 작게 유지해 과적합을 줄임. M3 Pro에서는 MPS로 빠르게 학습.

## 현재 결과 해석
- ML이 지나치게 1.0이 나오는 건 데이터가 적고 단일 split이라 “운 좋은 분할” 가능성. 교차검증으로 평균/분산을 보는 게 필요.
- DL은 val set이 작아 지표 변동이 크고 언더피팅/불안정. 리샘플 길이, lr, hidden 크기, 증강 강도 등을 조정하며 안정화 필요.

## 앞으로 해야 할 일 (우선순위)
1) **평가 신뢰도 개선**: ML에 외부 k-fold 평가 옵션 추가(5-fold), 깨끗/노이즈 별도 지표 기록.
2) **증강 재현성**: 학습에 쓴 합성/증강 샘플을 `experiments/augmented/` 등에 저장해 동일 실험을 재현 가능하게 하기.
3) **DL 튜닝**: 리샘플 길이 256→384 테스트, lr 1e-3 vs 5e-4, hidden 32/64, 증강 강도 조절. 필요 시 더 얕은 모델 실험.
4) **강건성 체크**: 깨끗/노이즈 각각 PR/혼동행렬을 시각화해 취약 클래스 파악.
5) **추론 데모**: 단일 txt를 입력받아 전처리→예측→3D 플롯/확률을 보여주는 스크립트 작성.

## 파라미터 조정 가이드 (요약)
- `--target-len`: 256(빠름) ↔ 384/512(정보 보존↑).
- `--synthetic-from-original`: 합성 노이즈 샘플 수(학습 전용). 값↑ → 데이터량↑, 합성 편향 주의.
- `--noise-strength`: 노이즈 프로파일 강도. 값↑ → 거칠게 노이즈화.
- SVM: `--search` + `--C-grid/--gamma-grid`로 탐색. C↑/gamma↑ → 경계 복잡도↑.
- DL: `--lr`(1e-3 기본, 5e-4 안정), `--batch-size`(8~32), `--val-ratio`(≥0.2), `--epochs`(early stopping 있음).

## 참고한 일반적 레퍼런스/아이디어
- SVM (RBF)와 특징 기반 시계열 분류: scikit-learn 기본 기법.
- 시계열 신경망: 1D CNN + BiLSTM 구조는 일반적인 시계열 패턴 학습용 소형 모델 패턴.
- 교차검증/PR 커브/혼동행렬: 표준 평가 지표 및 시각화 방법.

## 우리가 기대하는 결과
- ML: 소형 데이터에서도 안정된 성능, 특징 기반 해석 가능.
- DL: 적절한 튜닝 후 깨끗/노이즈 모두에서 균형 잡힌 성능과 강건성.
- 리포트/이미지: JSON+PNG로 지표와 혼동행렬/PR을 보고서·발표에 활용.
